mean(axis=2) # 지정한 AXIS ; 집계하고 싶은 대상
group by 반, 번호 # 나머지 axis는 group by
--------------------------------------------------------------------------------------------------------------
(2, 3, 1) 2 : 반, 3 : 개별 학생, 1 : 과목

s.mean() -> 전체 학생의 국어 점수의 평균

s.mean(axis=0) -> 0번 축(반)을 기준으로 평균 : 각 반의 1번, 2번, 3번 학생의 국어 평균
(1반, 1번, 국어)
 +
(2반, 1번, 국어)
=  1번 학생의 국어 평균
=> (0번 axis가 다른(반이 다른), 같은 index에 있는 애들(같은 번호, 과목이 같은)끼리 계산)

(1반, 2번, 국어)
 +
(2반, 2번, 국어)
=  2번 학생의 국어 평균

(1반, 3번, 국어)
 +
(2반, 3번, 국어)
= 3번 학생의 국어 평균

== (3, 1)
--------------------------------------------------------------------------------------------------------------
s.mean(axis=1) -> 1번 축(학생)을 기준으로 평균 : 반 별 국어 점수 평균
(1반, 1번, 국어) + (1반, 2번, 국어) + (1반, 3번, 국어)
=  1반의 국어 평균
=> (1번 axis가 다른(학생이 다른), 같은 index에 있는 애들(같은 반, 과목이 같은)끼리 계산)

(2반, 1번, 국어) + (2반, 2번, 국어) + (2반, 3번, 국어)
=  2반의 국어 평균

 == (2, 1)
--------------------------------------------------------------------------------------------------------------
s.mean(axis=2) -> 2번 축(과목)을 기준으로 평균 : 반과 학생
(1반, 1번, 국어) + (1반, 1번, 영어) 
= 1반 1번의 평균

(1반, 2번, 국어) + (1반, 2번, 영어)
= 1반 2번의 평균

(1반, 3번, 국어) + (1반, 3번, 영어)
= 1반 1번의 평균

(2반, 1번, 국어) + (2반, 1번, 영어)
= 2반 1번의 평균

(2반, 2번, 국어) + (2반, 2번, 영어)
= 2반 2번의 평균

(2반, 3번, 국어) + (2반, 3번, 영어)
= 2반 1번의 평균
